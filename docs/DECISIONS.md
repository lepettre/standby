# Festgehaltene Entscheidungen

| Entscheidung | Grund |
| --- | --- |
| Eine einzige HTML-Datei, kein Framework, kein Server | Läuft auf GitHub Pages und vom Home-Bildschirm, schnell auf dem iPhone |
| Referenzgerät iPhone 17, Prüfung in 874 × 402 und 402 × 874 | Referenzgerät |
| Keine Fremdfotos für Rezepte ohne geprüfte Zuordnung; stattdessen Farbkacheln nach Kategorie; Fotos nur eigene oder selbst bei Unsplash ausgewählte | Nichts Falsches zeigen |
| Keine leeren Hüllen: Die Gestirne übernehmen Inhalt und Optik original aus dem Vorbild | Echtheit |
| Pflichtsatz bei den Gestirnen: Horoskop aus Zitaten der Kritischen Theorie | Einordnung |
| Mengen immer mit Originaleinheit plus metrisch, Umrechnungen mit ≈ markiert | Grundregel |
| Smart Home in 3.x ausgeklammert; Home Assistant erst 5.0.0 | Fokus |
| Apple Erinnerungen entfernt | iOS gibt sie seit Version 13 nicht per CalDAV heraus; ginge nur über Kurzbefehle mit Worker oder eine Mac-Brücke |
| Bahnhofsuhr als eigene schlichte Variante, nicht die SBB-Uhr | Schutzrechte |
| Fehler als kurze Einblendung, nie als Zeile im Widget | Wunsch zu 3.0 |
| ARTE nur inoffiziell und brüchig, MUBI ohne Schnittstelle, Google Cast nicht in iPhone-Safari | Nicht umsetzbar |
| Monogramm-Kacheln für Rezepte | Abgelehnt |
| Nichts erfinden: fehlende Daten als Platzhalter oder offene Frage kennzeichnen | Grundregel |
